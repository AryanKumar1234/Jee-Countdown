# JEE Countdown 💀

**Your IIT dreams are getting closer. Your backlog isn't.**

A minimalist, cinematic JEE countdown Android app built for students who need a daily reminder that time is running out.

## ✨ Features

- ⏳ Live countdown with days, hours, minutes and seconds.
- 📚 Separate JEE Main and JEE Advanced countdowns.
- 📱 Dedicated home-screen widgets for both exams.
- 👀 Widget previews before adding them to your home screen.
- 🎨 Minimal black-and-red cinematic UI.
- ⚡ Responsive widgets with adaptive sizing.
- 🕒 Uses your device's system time.
- 🔄 Automatic countdown updates.
- 💀 169 randomized Gen-Z-style countdown messages.
- 🌐 Kannada, Hindi, Telugu and English flavour.

## 🧠 The Vibe

No unnecessary distractions.  
No complicated dashboards.  
Just your exam countdown staring directly into your soul.

## 🛠️ Tech

- Android application
- Native home-screen widgets
- Android system clock
- Responsive widget layouts

## 🚀 The Mission

Make studying feel urgent.

Because your competition isn't waiting for you to finish scrolling.
